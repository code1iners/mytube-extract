# 01: 공통 레이아웃과 탐색

Status: done (2026-10-03, 로컬 구현·검증 완료)

**What to build:** 사용자가 모바일에서는 하단 탭, 데스크톱에서는 왼쪽 메뉴로 영상 추출·자막 추출·요청 내역을 오가고, 헤더의 `…`에서 사용 안내와 설정을 여는 공통 화면을 제공한다. 승인된 무채색 방향과 기존 테마 선호를 실제 화면에 적용한다.

**Blocked by:** 없음 (선행 티켓 없음).

**기준:** Web 최소 구성 재설계 명세와 승인된 2차 시안. 관련 사용자 요구사항: 1, 2, 3, 5, 6, 7, 8, 9, 59, 60.

**착수 조건:** 2026-10-03 사용자가 이 티켓에 `$implement`를 요청해 제품 구현·검증·현재 브랜치 커밋을 승인했다.

## 완료 조건

- [x] 모바일 하단 고정 탭의 세 목적지를 유지하고, 데스크톱에서는 왼쪽 로고·세로 메뉴와 오른쪽 작업 영역을 제공한다. 기존 상단 탭은 데스크톱의 주 탐색에서 제거한다.
- [x] 모바일 820px 이하·데스크톱 821px 이상 경계를 유지하며 현재 목적지를 전달한다. 숨겨진 다른 크기의 메뉴는 키보드 탐색과 접근성 트리에 중복 노출되지 않는다.
- [x] 헤더 오른쪽에 가로 점 세 개 `…`만 표시하고 접근성 이름은 `더보기`로 유지한다. 사용 안내·설정, 열림 상태 전달, Escape·바깥 클릭 닫기와 닫은 뒤 포커스 복귀가 동작한다.
- [x] 접수 중에는 기존 주요 메뉴·설정 이동 잠금과 이유 전달을 유지한다. 접수 전 취소 또는 접수 완료 후 기존 규칙에 따라 이동할 수 있다.
- [x] 로고 아이콘의 빨강, 무채색 서비스 이름·주요 행동·선택 표시, 의미 있는 상태색과 Pretendard 단일 서체를 적용한다. 새 장식 이미지·등장 애니메이션을 도입하지 않는다.
- [x] 시스템·라이트·다크 테마 선택과 기억이 유지된다. Web 전용 디자인 변경이 Chrome 확장 프로그램의 색상·동작을 바꾸지 않는다.
- [x] 본문 끝까지 스크롤하면 모든 조작이 하단 탭과 안전 여백 위에 온전히 나타난다. 긴 내용과 200% 글자 확대에서도 수평 넘침과 탐색 가림이 없다.
- [x] 일반 텍스트 대비 4.5:1, 큰 텍스트·필요한 조작 경계·포커스 3:1, 주요 조작 영역 44×44px 이상을 확보한다.
- [x] 기존 브라우저 시나리오로 세 화면과 설정 이동, 보조 메뉴, 접수 중 이동 잠금을 검증한다. 라이트·다크 및 320·390·820·821·1280px 폭에서 공통 배치를 확인한다.
- [x] 마지막 변경 이후 관련 Web 정적 검사·기존 테스트·빌드·브라우저 결과를 기록하고 공통 탐색·Web 디자인 설명을 갱신한다. 로컬 검증과 실제 기기 검증을 구분한다.
