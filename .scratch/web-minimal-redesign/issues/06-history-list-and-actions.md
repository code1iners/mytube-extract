## 완료 조건

- [x] 반복 외곽 카드를 구분선 목록으로 바꾸고 제목·종류·품질 또는 처리 방식·요청 시각·상태·주요 행동을 항상 보인다. 부가 상세와 삭제만 펼쳐서 접근한다.
- [x] 요청 영상 제목이 있으면 기존 제목을 유지하고, 없으면 원본 주소로 식별한다. 긴 제목·주소·파일명을 읽고 사용할 수 있다.
- [x] 완료 항목의 다운로드와 실패·만료 항목의 `다시 요청`이 상세를 열지 않아도 보이고 조작 가능하다. 직접 재요청으로의 행동 전환은 07·08에서 완료한다.
- [x] 공통 단계 표시와 완료된 100% 막대를 제거한다. 처리 중에는 실제 상태·확인 가능한 진행률만 표시하고, 완료·실패·만료·조회 오류와 각 복구 동작을 구분한다.
- [x] 다운로드 주소가 없는 완료 응답을 정상 다운로드처럼 표시하지 않고 기존 조회 복구를 유지한다. 정상 완료 항목의 결과·필요한 보관 안내·다운로드가 동작한다.
- [x] 기존 종류·작업 식별자·접수 시각으로 이루어진 접수증, 최신 접수순 최대 20건, 직접 내역 연결과 다른 탭의 변경 반영을 유지한다. 원본 파일·제목·재요청 조건을 접수증에 새로 저장하지 않는다.
- [x] 처리 중 요청의 주기적 조회와 완료·실패·만료의 조회 중단을 유지한다. 일시적인 네트워크·서버 오류에서는 내역을 보존하고 404에서만 기존 규칙대로 정리한다.
- [x] 브라우저 저장 실패가 서버 작업 실패로 보이지 않는다. 현재 세션의 접수된 요청 접근을 유지하고 새로고침 이후 복구까지 보장하지 않는다.
- [x] 삭제는 접수증만 제거하며 서버 작업을 취소하지 않는다. 최근 한 건의 8초 되돌리기, 저장 실패 안내와 다른 탭 동기화를 유지한다.
- [x] 삭제 후 실제 보이는 다음 항목의 조작 → 이전 항목의 조작 → 목록 제목 순으로 포커스를 복귀시킨다. 닫힌 상세 안의 버튼에 포커스를 보내지 않고, 되돌린 항목은 제목이나 첫 조작에서 식별할 수 있게 한다.
- [x] 빈 내역에서 영상·자막 시작점과 현재 브라우저의 내역·완료 파일 보관 범위를 간결하게 안내한다.
- [x] 라이트·다크, 긴 내용, 320·390·1280px 폭과 200% 글자 확대에서 읽기·조작·하단 탭 가림을 확인한다. 명세의 대비·44×44px 조작 영역·키보드 상세 조작을 충족한다.
- [x] 기존 브라우저 시나리오로 주요 행동 노출, 제목 대체, 조회 갱신·중단, 조회 오류·404, 삭제·되돌리기·포커스, 저장 실패·다른 탭 동기화를 검증한다.
- [x] 마지막 변경 이후 관련 정적 검사·자동 테스트·빌드·브라우저 결과를 기록하고 내역의 목록·상세·삭제·진행 표시 설명을 갱신한다.
