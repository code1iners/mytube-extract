# 02: 팝업 화질 입력을 고정 선택지로 전환

**What to build:** 팝업에서 오디오/비디오 화질을 고를 때 임의의 숫자를 입력하는 대신, 서버가 실제로 지원하는 고정된 화질 값 중에서 선택하게 한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 오디오 모드에서 128 / 192 / 320 중에서만 고를 수 있다.
- [ ] 비디오 모드에서 360 / 720 / 1080 중에서만 고를 수 있다.
- [ ] 선택한 값은 여전히 기존 직접 다운로드 흐름(현재 `/audio`, `/video` API)에 그대로 전달돼 지금과 동일하게 동작한다.
- [ ] 저장된 옵션을 불러올 때 유효하지 않은 값이면 기본값으로 대체된다.
