**What to build:** YouTube 페이지의 썸네일 다운로드 버튼도 직접 다운로드 API 대신 job 기반 흐름을 사용한다.

**Blocked by:** 03

**Status:** done (구현 cc4924e)

- [x] 오버레이 버튼 클릭 시 직접 다운로드 API 대신 job이 생성된다.
- [x] 클릭 직후 페이지 내 알림(toast)은 "요청을 시작했습니다" 같은 접수 확인만 표시하고 사라진다.
- [x] job이 완료되면 영상 제목 기반으로 정리된 파일명으로 자동 다운로드된다(기존 파일명 정리 로직 재사용).
- [x] 오버레이에서 만든 job도 background의 동일한 추적 로직을 그대로 사용한다(목록/알림은 각각 06/07이 랜딩된 이후 자동으로 적용되며, 이 티켓에서 오버레이 전용 UI를 새로 만들지 않는다).
