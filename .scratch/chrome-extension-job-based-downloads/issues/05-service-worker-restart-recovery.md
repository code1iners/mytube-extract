# 05: Service worker 재시작/휴면 이후 진행 중 job 추적 복구

**What to build:** service worker가 중간에 종료되거나 브라우저가 재시작되어도, 아직 끝나지 않은 요청의 추적이 스스로 재개된다.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] service worker가 유휴 상태로 종료된 뒤 다시 깨어나면, 아직 끝나지 않은 job의 상태 확인이 다시 이어진다.
- [ ] 브라우저를 완전히 재시작해도 재시작 전에 대기/처리 중이던 job이 다시 추적된다.
- [ ] 이미 완료되거나 실패해 있던 job은 재시작 후 다시 폴링하지 않는다.
- [ ] 재개 시나리오가 실제 타이머·브라우저 재시작 없이 가짜 스케줄러로 검증된다.
