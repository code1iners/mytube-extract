# 04: 팝업 종료 후에도 추적 유지 — background 영속 저장 + 팝업 상태 구독

**What to build:** 요청을 보낸 뒤 팝업을 바로 닫아도 background가 계속 추적하고, 팝업을 다시 열면 최신 상태를 보여준다.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 제출 직후 팝업을 닫아도 job 추적이 background에서 계속된다.
- [ ] job이 완료되면 팝업이 닫혀 있는 상태에서도 로컬 다운로드가 자동으로 시작된다.
- [ ] 팝업을 다시 열면 저장된 최신 상태(대기/처리 중/완료/실패)가 즉시 보인다.
- [ ] 팝업이 열려 있는 동안 상태가 바뀌면 팝업을 새로고침하지 않아도 화면이 갱신된다.
- [ ] 팝업은 더 이상 자체적으로 서버 상태를 조회하지 않는다 — 유일한 조회 주체는 background이다.
