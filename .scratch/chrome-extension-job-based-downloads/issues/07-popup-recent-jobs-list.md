# 07: 팝업 최근 요청 목록 UI + 자동 보관 정책

**What to build:** 팝업이 "새 요청 폼 + 최근 요청 목록"으로 바뀌어, 여러 요청을 연달아 보내도 각각 독립적으로 진행 상황을 확인할 수 있다.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 팝업 상단에는 항상 새 요청 폼이 보인다.
- [ ] 폼 아래에 최근 요청 목록이 스크롤 가능한 형태로 보인다.
- [ ] 목록의 각 항목은 자신의 상태(대기/처리 중/완료/실패)를 독립적으로 보여준다.
- [ ] 완료·실패한 요청이 6번째로 쌓이면 가장 오래된 완료·실패 항목부터 자동으로 제거된다.
- [ ] 아직 대기 중이거나 처리 중인 요청은 목록이 가득 차도 자동으로 제거되지 않는다.
