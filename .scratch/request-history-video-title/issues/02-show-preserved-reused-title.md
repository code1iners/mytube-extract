# 02: 재사용 결과물의 제목 보존과 내역 표시

**What to build:** 기존 결과물을 재사용하는 영상·오디오 요청에서 원본 제목을 요청에 보존하고 내역의 주 제목으로 표시한다. 제목이 없으면 원본 영상 링크로 요청을 구분하며, 결과물이 정리되어도 확보한 제목은 남는다.

**Blocked by:** 없음 (즉시 시작 가능).

Status: ready-for-agent

- [ ] 추출 요청에 선택적 요청 영상 제목을 호환적으로 추가한다. null·빈 문자열·공백뿐인 제목은 미확보로 처리하며 결과물 제목과 다운로드 파일명 계약은 유지한다.
- [ ] 서버 접수 시 결과물을 재사용하는 경로와 작업 처리 중 결과물을 재사용하는 경로 모두에서 유효한 제목을 요청에 복사한다. 외부 제목 조회를 추가하지 않는다.
- [ ] 이미 확보된 요청 제목을 변경하지 않는다. 이후 결과물 제목이 바뀌어도 요청에는 처음 확보한 제목이 남는다.
- [ ] 접수·상태 조회 응답과 Web 응답 검증에 요청 제목 및 저장된 YouTube 식별 정보 기반 원본 링크를 함께 반영한다. 기존 응답 필드의 의미는 유지한다.
- [ ] 요청 내역에서 제목을 주 제목으로 표시하고 비디오·오디오 구분, 품질, 요청 시각과 상태를 보조 정보로 유지한다. 제목이 없으면 영상 식별자가 보이는 원본 링크로 구분한다.
- [ ] 제목을 일반 텍스트로 표시하고 기본 줄바꿈 및 접근 가능한 항목 제목 연결을 유지한다. 브라우저 접수증에 제목·링크를 추가 저장하지 않는다.
- [ ] 테스트가 소유하는 실제 로컬 데이터베이스 요청으로 재사용 접수 → 상태 조회 → 결과물 만료 → 실제 결과물 행 정리 → 상태 재조회를 연결하여 같은 제목이 남음을 확인한다. 제목 없는 재사용 결과물도 확인한다.
- [ ] 기존 브라우저 검증에서 제목 있는 요청·없는 요청, 비디오·오디오, 새로고침 후 표시를 확인한다. 서버 응답 대역의 화면 증거와 실제 데이터베이스 보존 증거를 구분한다.
- [ ] 마지막 변경 이후 관련 데이터 모델·서버·Web·작업 처리기의 정적 검사와 테스트를 실행한다. 필요한 검증 환경이 없어 실행하지 못한 검사를 통과로 처리하지 않는다.

## 범위 경계

신규 추출의 제목 조기 저장은 03, 과거 요청의 일괄 이관은 04, 상세 화면 조작 검증은 05에서 수행한다. 여기서 만든 데이터베이스 검증 경계를 후속 티켓이 재사용한다. 이 티켓 단독 완료는 기존 제목 이관을 포함한 운영 전환 완료를 의미하지 않는다.
