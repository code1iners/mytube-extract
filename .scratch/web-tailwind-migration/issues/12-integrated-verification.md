# 12: 전체 화면 통합 검증

Status: done (2026-09-08)

**What to build:** 검토자가 전환 전후 증거와 최신 검사 결과로 Web 앱의 디자인·동작 보존을 확인하고 미검증 환경을 구분할 수 있다.

**Blocked by:** 11: 이전 화면 스타일 정리

## 완료 조건

- [x] 각 티켓의 증거를 모아 네 주요 화면과 준비·입력 오류·접수·중단·진행·완료·실패·만료·빈 내역·삭제·되돌리기 상태의 누락을 확인한다.
- [x] 최종 구현을 최초 기준과 라이트·다크 각각 320×844·390×844·1280×900에서 비교한다. 단계별 비교만으로 누적된 시각 변경을 놓치지 않게 한다.
- [x] 반응형 전환점 직전·직후, 시스템 테마와 저장 선호, 200% 글자 확대 proxy·움직임 감소·터치 영역·키보드 탐색과 실제 포커스를 최종 확인한다.
- [x] 영상·자막 입력부터 접수와 결과, 요청 내역 이동·삭제·되돌리기 및 설정까지 연결된 사용자 동작을 기존 브라우저 경계에서 검증한다.
- [x] 최종 변경 이후 타입 정적 검사·전체 단위 테스트·배포용 빌드와 패키징 검사·기존 브라우저 smoke의 유효한 결과를 확보한다. 실패를 검사 삭제·성공 처리·임의 건너뛰기로 숨기지 않는다.
- [x] 발견한 회귀를 소유 영역에 연결하고 수정 후 영향 범위를 재검증한다. 큰 미완료 전환을 이 티켓에 몰아넣거나 회귀가 남은 상태를 완료로 표시하지 않는다.
- [x] 남은 전역 규칙과 실제 서버·처리기·제공자·외부 저장소, 물리 기기·화면 낭독기·운영 환경의 미검증 경계를 보고한다. 로컬 증거로 실제 환경 성공을 주장하지 않는다.

## 공통 보존·검증 조건

- [x] 최신 디자인·동작 계약과 별도 작업 변경을 보존한다. Chrome 확장 프로그램·Popup, 서버 요청·응답·저장 정책 및 제품 기능은 변경하지 않는다.
- [x] 변경 전후 동일한 브라우저·폰트·fixture·화면 상태를 사용하고 변동 요소를 통제한다. 해당 영역의 시각·키보드·동작 회귀를 이 티켓에서 해결한다.
- [x] 기존 브라우저 사용자 동작 검증과 관련 단위 검사를 재사용한다. 마지막 관련 변경 이후 타입 검사·전체 단위 테스트·배포용 빌드·기존 브라우저 smoke 결과와 미검증 경계를 기록한다.

## 범위 경계

각 전환 티켓 자체 검증을 대체하지 않는다. 새 기능·배포·커밋·푸시를 이 티켓의 기본 산출물로 추가하지 않는다.

이 티켓은 확정된 Web 앱 Tailwind CSS 전환 스펙을 따른다. 상태 표시는 작업 준비 상태이며, 티켓 게시 자체가 코드 구현 착수를 뜻하지 않는다.
