    4. 선택한 품질 숫자의 밑줄은 시안에 없다(`DESIGN.md` 11절의 "색만으로 선택을 전달하지 않는다").

    - 1·2는 `DESIGN.md` "열린 결정"에 "구현됨, 사용자 확인 대기"로 적었다.
