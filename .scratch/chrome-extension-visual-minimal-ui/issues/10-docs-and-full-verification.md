# 10: 문서 갱신과 전체 브라우저 검증

**What to build:** 새 동작에 맞춰 저장소 문서를 갱신하고 마지막 변경 이후 전체 검증을 실행한다.
- `DESIGN.md`에 Chrome popup·Overlay 최소 UI 계약 절을 추가한다: 무대, 빨강 = 액션 전용, 상태색은 배지에만, 오류에만 문장, 44px 조작 영역, 숫자 없는 진행 링.
- 확장 PRD·FSD에서 현재 탭 자동 읽기, Overlay 진행 표시, 파일명 비저장, 설정 화면, 권한 해제 서술을 갱신한다.
- 글로서리에 필요한 용어(예: "무대")를 추가한다.
- 이전 job 전환 스펙과 대체된 결정 사이의 관계를 문서에 남긴다.
