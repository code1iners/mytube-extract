# 02: 프리팩터: job에 원본 주소·요청 영상 제목 보존

**What to build:** 확장 프로그램이 API job 응답의 원본 YouTube 주소와 요청 영상 제목을 버리지 않고 job 표현과 최근 요청 저장소에 보존한다. 원본 주소에서 영상 ID를 얻을 수 있게 한다. 화면은 아직 바뀌지 않는다. 최근 요청 썸네일(06)과 Overlay 카드 상태(09)가 이 데이터를 사용한다. API 계약은 바꾸지 않는다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] API client가 job 응답의 원본 주소와 요청 영상 제목을 job 표현에 담는 것을 단위 테스트로 확인한다(제목이 null인 경우 포함).
- [ ] 최근 요청 저장소가 두 필드를 저장·복원하고, 두 필드가 없는 예전 저장 job도 오류 없이 읽힌다(필드는 비어 있는 값으로 복원)는 것을 단위 테스트로 확인한다.
- [ ] job에서 영상 ID를 얻는 동작이 watch·Shorts·youtu.be 원본과 필드 없는 job에 대해 기대값을 돌려준다는 것을 단위 테스트로 확인한다.
- [ ] 기존 Popup·background 동작이 바뀌지 않았음을 기존 단위·통합 테스트 전체 통과로 확인한다.
- [ ] 확장 `lint`와 `test`가 통과한다.
