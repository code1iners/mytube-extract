# 05: 파일명 편집

**What to build:** 무대 아래 제목 줄을 저장될 파일명으로 쓴다. 연필 버튼(44px)을 누르면 제목 줄이 입력칸과 확장자 표시(`.mp3`/`.mp4`)로 바뀐다. Enter나 체크 버튼으로 확정하고, 빈 값으로 확정하면 기본 이름(제목 기반 정리, 실패 시 영상 ID)으로 돌아간다. 파일명은 더 이상 저장소에 저장하지 않는다. 원본 영상이 바뀌면 비운다. 진행 중에는 편집할 수 없다. 기존 파일명 sanitize는 유지한다.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] model 통합 테스트: 편집한 파일명이 sanitize되어 제출에 쓰이고, 빈 값이면 기본 이름이 쓰인다.
- [ ] model 통합 테스트: 파일명은 저장소에 저장되지 않고, 원본 영상이 바뀌면 비워진다. 예전에 저장된 파일명 값은 무시된다.
- [ ] popup 브라우저 스모크가 연필 → 입력 → Enter 확정 → 제출 흐름을 키보드로 확인하도록 갱신되어 통과한다.
- [ ] 확장 `lint`, `test`, `build`가 통과한다.
