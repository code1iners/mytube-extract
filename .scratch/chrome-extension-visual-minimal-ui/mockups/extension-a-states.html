A안 · 상태 화면

썸네일 무대 방향을 코드의 모든 상태에 대응시켰어요. 맨 위 프로토타입은 끝까지 눌러볼 수 있고, 아래는 상태 하나당 화면 하나씩입니다. 회색 작은 글씨는 대응하는 코드 상태값이에요.

눌러보는 프로토타입

제목 옆 연필로 파일명을 바꾸고, 형식·품질을 고른 뒤 빨간 버튼을 눌러 보세요. 아래 썸네일 줄을 누르면 최근 요청, 오른쪽 위 아이콘을 누르면 썸네일 버튼 권한과 설정이 열려요.

  1. 버튼을 누르면 서버 확인 → 대기 → 처리 → 완료 순서로 썸네일 위에서 진행돼요.
  2. 진행 중에는 형식·품질이 잠기고, 버튼은 회색 회전 아이콘이 돼요.
  3. 끝나면 새 썸네일이 최근 요청 줄 맨 앞에 붙어요.

요청 전

URL은 기본적으로 현재 탭에서 가져와요. 유튜브가 아닌 탭에서만 붙여넣기 칸이 나타나고, 입력 오류는 그 칸이 직접 보여줘요.

진행

진행은 썸네일 위에서만 보여줘요. 링 색은 흰색, 상태색(회색·파랑·초록)은 아래 최근 요청 배지에서 써요. 빨강은 버튼에만 남겨요.

문제

오류에만 한 줄 문장을 남겨요. 아이콘만으로는 무엇을 해야 하는지 알 수 없기 때문이에요. 다시 시도는 같은 빨간 버튼이 회전 화살표로 바뀌는 방식이에요.

최근 요청 · 설정 · 썸네일 버튼 권한

최근 요청은 썸네일 줄을 누르면 펼쳐져요. 권한은 오른쪽 위 격자 아이콘의 점으로 알려줘요: 빨간 점은 아직 켜지 않음, 초록 점은 켜짐, crimson 점은 거부됨이에요.

유튜브 썸네일 오버레이

썸네일에 마우스를 올리면 오른쪽 위에 형식 두 개와 품질 막대 세 개가 나와요. 품질을 누르면 바로 접수되고, 이후 상태는 같은 자리의 작은 링과 화면 구석의 토스트로 보여줘요.
