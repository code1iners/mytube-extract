# 03: 비지원 파일의 사전 불가 표시

Status: ready-for-agent

**What to build:** 드래그 중 명확한 비지원 파일 형식이 확인되면 불가 표시를 보여 준다. 정보가 불명확하면 위치 안내를 유지하고, 실제 놓기 후 최종 검증과 기존 선택 보존으로 연결한다.

**Blocked by:** 01 — 잘못된 파일을 놓아도 기존 선택 보존; 02 — 드래그 위치 강조와 안정적인 복원.

## 완료 조건

- [ ] `image/png`, `text/plain`처럼 명확한 비지원 형식이면 오류색 테두리·금지 아이콘과 `지원하지 않는 파일 형식입니다` 문구를 표시한다. 브랜드 액션 빨강 대신 기존 오류색 토큰을 사용한다.
- [ ] 드래그 중 제공되는 MIME (영문 원문: Multipurpose Internet Mail Extensions: 파일 형식을 나타내는 표준 식별 정보) 등 형식 정보만 사용한다. 실제 파일 이름·확장자·용량·내용을 읽을 수 있다고 가정하지 않는다.
- [ ] 지원 형식은 02번의 위치 안내를 사용한다. 빈 형식이나 일반 바이너리 정보처럼 판별할 수 없는 경우도 위치 안내를 유지한다. 정보 부족만으로 미리 거부하지 않는다.
- [ ] 사전 불가 표시가 있더라도 실제 놓기에서 기존 파일 검증으로 최종 판단한다. 브라우저의 파일 열기 동작으로 빠지지 않고 01번의 오류 안내·선택 보존으로 연결한다.
- [ ] 드래그 중 정보가 없었지만 실제 파일이 유효하면 정상 선택한다. 놓은 뒤 형식 불일치나 빈 MIME으로 거부되면 기존 영상·처리 방식·제출 대상 또는 빈 상태를 보존한다.
- [ ] 복수 파일은 기존 첫 파일 정책과 사전 안내를 일치시킨다. 뒤의 비지원 파일 때문에 첫 정상 파일을 사전 거부하지 않으며, 순서나 대상이 불명확하면 불가로 단정하지 않는다.
- [ ] 기존 오류 문구는 드래그 중에도 유지하고, 박스 표시는 현재 드래그의 위치 안내 또는 불가 표시를 우선한다. 이탈·취소 시 기존 오류 표시로 복원한다.
- [ ] 불가 표시에서도 내부 이동 시 깜빡임 방지, 놓기·취소 후 복원, 박스 크기 유지와 접근 가능한 오류 전달을 유지한다. 상태를 색만으로 전달하거나 반복 알림을 발생시키지 않는다.

## 검증

- [ ] 기존 자막 화면 브라우저 테스트에서 지원·명확한 비지원·불명확 형식의 세 경로를 검증한다. 드래그 중에는 형식 정보만 제공하고 파일 목록은 보호된 조건으로 재현한다.
- [ ] 사전 불가 → 실제 놓기 → 새 오류 안내 및 기존 선택 보존을 검증한다. 기존 선택이 없는 경우와 정상 영상이 있는 경우를 모두 포함한다.
- [ ] 불명확한 사전 정보 → 정상 선택 또는 최종 거부, 지원 MIME과 잘못된 확장자, 실제 빈 MIME을 검증한다. 허용 목록이 완화되지 않았음을 확인한다.
- [ ] 복수 파일의 첫 파일 기준, 파일이 아닌 링크·텍스트 드래그, 기존 오류와 드래그 표시의 우선순위를 확인한다.
- [ ] 실제 운영체제 파일 관리자에서 지원 파일과 비지원 파일을 드래그해 표시·복원·최종 오류·기존 선택 보존을 통합 확인한다. 실제로 얻은 형식 정보가 불명확하면 이를 기록하고, 불명확 경로와 확정 불가 경로의 증거를 구분한다.
- [ ] 실제 드래그 검증의 운영체제·브라우저·시나리오·결과를 기록한다. 실행하지 못한 경계는 미검증으로 남기며 합성 이벤트 통과로 대체하지 않는다.
- [ ] 라이트·다크 테마, 좁은 화면, 클릭·Enter·Space 파일 선택, 실제 포커스 표시를 포함해 세 티켓이 결합된 최종 화면을 회귀 확인한다.
- [ ] 마지막 변경 후 Web 정적 검사·단위 테스트·기존 브라우저 테스트 결과를 기록한다. 화면 관찰과 실제 입력·선택 결과를 검사하며 내부 구현 세부사항만 확인하지 않는다.

## 범위와 인계

- 두 선행 티켓의 결과를 사용하는 좁은 통합 작업이다. 별도 테스트 환경이나 신규 외부 의존성을 만들지 않는다.
- 파일 내용·용량·코덱 판정, 지원 형식 확대, 복수 파일 일괄 처리, 디렉터리 업로드, 서버·저장소·추출 요청 생명주기 변경은 포함하지 않는다.
- 이 티켓 완료 보고에서 자동 검증과 실제 파일 드래그 검증을 분리하고, 남아 있는 실환경 미검증 항목을 명시한다.
