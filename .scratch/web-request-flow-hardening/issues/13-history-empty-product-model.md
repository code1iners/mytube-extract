# 13: 빈 요청 내역에서 두 추출 흐름과 보관 모델 안내

**What to build:** 요청 내역이 비어 있을 때 사용자가 영상·오디오 추출과 영어 자막 생성 중 원하는 작업을 바로 시작할 수 있게 한다. 동시에 이력은 현재 브라우저에만 저장되고 완료 파일은 7일 동안 보관된다는 MyTube Extract의 작업 모델을 행동 맥락 안에서 이해하게 한다.

**Blocked by:** 12: 주요 내비게이션을 영상·자막·내역으로 통합

**Status:** ready-for-agent

- [ ] 빈 요청 내역에서 YouTube URL 기반 영상·오디오 추출과 로컬 영상 기반 영어 자막 생성이 동등한 두 진입점으로 제공된다.
- [ ] 각 진입점의 출발 입력과 받을 결과가 기술 지식 없이도 구분된다.
- [ ] 이력은 현재 브라우저에만 저장되고 완료 파일은 7일 동안 보관된다는 안내가 짧고 명확하게 표시된다.
- [ ] 두 진입점은 12에서 확정한 주요 목적지와 같은 route·용어를 사용하며 키보드와 터치로 이동할 수 있다.
- [ ] 기존 요청이 하나 이상 있을 때의 최신순 목록, 상태 조회, 다운로드, 다시 요청, 내역 삭제 동작은 변경되지 않는다.
- [ ] 빈 상태의 두 진입점과 운영 안내를 검증하는 단위 테스트 및 모바일·데스크톱 브라우저 검증이 추가된다.
