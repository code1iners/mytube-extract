# 06: 마지막 요청 선호(형식·품질·Whisper 모델) 기억

**What to build:** 같은 브라우저에서 마지막으로 선택한 요청 형식(오디오/비디오), 품질(비트레이트/해상도), Whisper 모델을 저장하고, 다음 방문 시 그 값을 기본 선택지로 되살린다. 원본 URL·파일명 등 PRODUCT.md가 "미저장" 대상으로 규정한 값은 저장하지 않는다.

**Blocked by:** None (can start immediately)

**Status:** done (2026-09-01)

- [x] `/subtitles`에서 Whisper 모델(빠름/정확도)을 고르고 다시 방문하면 마지막 선택이 기본값으로 채워진다.
