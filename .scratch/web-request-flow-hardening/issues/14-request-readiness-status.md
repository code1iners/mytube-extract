# 14: 요청 전에 API·worker 준비 상태 표시

**What to build:** 영상 또는 자막 요청을 설정하기 전에 사용자가 서버 연결과 worker 준비 여부를 알 수 있게 한다. 확인 중·준비됨·중단됨·확인 실패 상태, 마지막 확인 시각, 재확인 동작을 폼 상단에서 제공하고 제출할 수 없는 이유를 주요 버튼 가까이에서도 설명한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 영상 추출과 자막 추출의 요청 단계에서 폼 입력보다 먼저 서버 연결 및 worker 준비 상태를 확인할 수 있다.
- [ ] 확인 중, 준비됨, worker 중단, 상태 확인 실패가 색상에만 의존하지 않는 텍스트와 아이콘으로 구분된다.
- [ ] 마지막 상태 확인 시각과 `다시 확인` 동작이 제공되며, 재확인 중에는 중복 요청 없이 최신 상태로 갱신된다.
- [ ] 제출 버튼이 비활성화됐을 때 그 이유가 버튼과 가까운 위치에서 연결돼 설명된다.
- [ ] 이미 접수된 작업의 처리·완료·실패 화면은 새로운 요청 readiness 상태로 덮이지 않고 기존 job 상태를 유일한 근거로 유지한다.
- [ ] 두 route의 준비됨·중단됨·확인 실패·재확인 상태와 접근성 공지를 검증하는 단위 테스트 및 브라우저 검증이 통과한다.
