# 17: 자막 처리 방식의 속도·정확도 차이 설명

**What to build:** 사용자가 Whisper 모델명을 미리 알지 않아도 속도 우선과 정확도 우선 처리 방식 중 적합한 선택을 할 수 있게 한다. 영어 전용·로컬 처리라는 제품 특성과 상대적 차이를 결정 지점에서 설명하고, 자막 화면의 용어와 처리 단계 표시를 일관되게 정리한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 선택 영역의 주 제목은 구현 기술보다 사용자의 결정인 `처리 방식`을 중심으로 설명한다.
- [ ] 속도 우선과 정확도 우선 옵션은 각각의 상대적 장점이 드러나며 `base.en`과 `small.en` 모델명은 보조 정보로 제공된다.
- [ ] 영어 전용이며 로컬 Whisper로 처리된다는 사실이 선택 시점에 짧게 안내되고, 검증되지 않은 시간·정확도 수치는 만들지 않는다.
- [ ] 화면 문구에서 자막 추출, 영어 SRT 생성, 처리 단계의 의미가 서로 충돌하지 않는 일관된 용어를 사용한다.
- [ ] 네 개의 자막 처리 단계가 데스크톱에서 빈 다섯 번째 열 없이 표시되고 320px·390px에서도 읽기 쉬운 구조를 유지한다.
- [ ] 선택값과 API에 전달되는 모델 계약은 변경되지 않으며, 두 옵션의 문구·선택·반응형 표시를 검증하는 테스트가 통과한다.
