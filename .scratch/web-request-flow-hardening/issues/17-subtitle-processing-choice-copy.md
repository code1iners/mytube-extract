# 17: 자막 처리 방식의 속도·정확도 차이 설명

**What to build:** 사용자가 Whisper 모델명을 미리 알지 않아도 속도 우선과 정확도 우선 처리 방식 중 적합한 선택을 할 수 있게 한다. 영어 전용·로컬 처리라는 제품 특성과 상대적 차이를 결정 지점에서 설명하고, 자막 화면의 용어와 처리 단계 표시를 일관되게 정리한다.

**Blocked by:** None (can start immediately)

**Status:** done (2026-09-02)

- [x] 선택 영역의 주 제목은 구현 기술보다 사용자의 결정인 `처리 방식`을 중심으로 설명한다.
- [x] 속도 우선과 정확도 우선 옵션은 각각의 상대적 장점이 드러나며 `base.en`과 `small.en` 모델명은 보조 정보로 제공된다.
- [x] 영어 전용이며 로컬 Whisper로 처리된다는 사실이 선택 시점에 짧게 안내되고, 검증되지 않은 시간·정확도 수치는 만들지 않는다.
- [x] 화면 문구에서 자막 추출, 영어 SRT 생성, 처리 단계의 의미가 서로 충돌하지 않는 일관된 용어를 사용한다.
- [x] 네 개의 자막 처리 단계가 데스크톱에서 빈 다섯 번째 열 없이 표시되고 320px·390px에서도 읽기 쉬운 구조를 유지한다.
- [x] 선택값과 API에 전달되는 모델 계약은 변경되지 않으며, 두 옵션의 문구·선택·반응형 표시를 검증하는 테스트가 통과한다.

## Comments

- 선택 영역을 `처리 방식`으로 바꾸고 `속도 우선`·`정확도 우선`의 상대적 의미와 `base.en`·`small.en` 보조 정보를 함께 표시했다.
- 선택 시점에 `영어 전용 자막을 로컬 Whisper로 처리합니다.`를 안내하고, 검증되지 않은 처리 시간 추정 문구와 계산 로직을 제거했다.
- 화면·API·워커의 자막 상태 문구를 `영어 SRT` 기준으로 정리했으며, `base_en`·`small_en` 선택값과 API 계약은 유지했다.
- 처리 단계 그리드를 네 칸으로 고정하고 320px·390px 반응형 표시 및 선택 상태를 브라우저 테스트로 검증했다.
