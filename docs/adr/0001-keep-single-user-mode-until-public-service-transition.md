# 공개 서비스 전환 전까지 개인 사용 단계를 유지한다

현재 MyTube Extract Web은 한 사람이 자신의 브라우저에서 사용하는 구조이므로, 지금은 로그인·사용자 계정·서버 기반 사용자별 요청 소유권을 도입하지 않는다. Web의 설정 영역에서는 테마 선호만 제공하고, 여러 사용자를 대상으로 서비스를 공개할 시점에 인증·소유권·보존 정책을 하나의 경계로 다시 설계한다.

## 고려한 선택지

- 지금 로그인과 계정 모델을 도입한다.
- 개인 사용 단계를 유지하고 공개 서비스 전환 시 인증과 사용자 모델을 설계한다.

두 번째 선택지를 택한 이유는 현재 사용자가 한 명이고, 지금 계정을 도입하면 제품 흐름보다 인증·사용자 데이터 운영 비용이 먼저 커지기 때문이다.

## 결과

- 현재 설정 탭은 계정 화면이 아니라 앱 환경설정 영역으로 유지한다.
- 요청 내역은 현재 사용자의 브라우저 중심 범위이며, 다른 기기 동기화나 사용자별 소유권을 제공한다고 가정하지 않는다.
- 공개 서비스 전환 전에는 인증 방식, 사용자와 요청의 소유권, 보존·삭제 정책, 기기 간 동기화, abuse/rate limit 정책을 결정해야 한다.

## 재검토 조건

다른 사람이 실제로 사용하거나, 다른 브라우저·기기에서 요청 내역을 이어서 확인해야 하거나, 사용자별 quota·보존·삭제를 적용해야 할 때 이 결정을 재검토한다.
